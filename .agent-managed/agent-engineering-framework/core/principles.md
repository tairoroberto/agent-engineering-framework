# Core principles

- Discover targeted project instructions before meaningful work. Do not crawl a repository without task-relevant reason.
- Project rules and current source govern project behavior. Framework rules do not replace them.
- Orchestrator owns scope, decomposition, dependencies, consolidation, completion. Subagents return evidence; they do not redefine scope.
- Delegate only for leverage: independent exploration/review/verification, isolated implementation, specialist knowledge, uncertainty reduction.
- Simple work stays single-agent. Missing evidence or overlapping ownership means sequential work.
- Preserve existing work. No destructive history operations, secret capture, or external side effects without authorization.
