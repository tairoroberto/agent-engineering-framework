# Engineering protocol

Load only documents needed. Canonical policy lives in `../../core/`; do not copy or override it here.

1. Read project AGENTS.md and `.agent-framework.toml`.
2. Read relevant core policy: principles always; orchestration for delegation; verification for review/gates; memory for substantial/resumed work; handoff for transfer; Caverman for communication.
3. Read selected profile and project rules. Project rules choose commands, architecture, domain behavior, release policy.
4. Load `../../agents/` role guidance only for dispatched role.
5. Use `references/routing-policy.json` as overridable default for complexity/risk/capability routing. Harness maps model classes locally.

Protocol does not own project state, test commands, business rules, or harness syntax. Harness adapters explain discovery only. ai-memory is historical context, never authority.
