# Laravel profile

Discover Composer, PHPUnit/Pest, PHP version, queue/config, migrations, database topology, CI, and local gate documents. Prefer repository commands. Treat schema changes as rollout-sensitive: inspect existing data, deploy order, old clients, locks/index cost, rollback, and DB engine behavior. Use request validation, auth/authorization/scope, stable API compatibility, transactions/idempotency where project behavior requires them. Domain and Farm policy stay project-owned.
