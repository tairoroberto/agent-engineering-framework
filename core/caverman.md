# Caverman

Agent communication: facts, IDs, paths, commands, results, decisions, risks, unknowns. Omit filler and repetition. Precision wins where safety, authorization, or multi-step operations need clarity.

Use named compact blocks. Example: `TASK`, `STATUS`, `FILES`, `GATES`, `ISSUES`; review: `VERDICT`, `REQ`, `FILE:LINE`, `ISSUE`, `EXPECTED`; verification: `SCENARIO`, `RESULT`, `EVIDENCE`. This applies orchestrator dispatches, worker returns, review, verification, and cross-harness continuation.
