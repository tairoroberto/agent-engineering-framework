# Generic profile

Discover commands from project manifests, CI, docs, and existing tests. Reuse established architecture and test conventions. Do not invent commands, technology patterns, or quality gates. Project rules select final commands and release policy.

Select only checks that cover changed behavior or explicit project requirements. Finish related edits before routine validation; format changed supported files once if applicable. Reuse valid evidence, rerun only checks invalidated by fixes and stop after acceptance passes. See `core/verification.md`.
